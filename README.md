# MediaShelf — финальный Android-проект

Проект развивает базовый Android-проект на Kotlin + Jetpack Compose в offline-first приложение каталога персонажей Rick and Morty.

## Реализовано
- Каталог из публичного Rick and Morty API (Retrofit + kotlinx.serialization).
- Room как источник данных для UI: кэш каталога, пользовательские статусы, закрепление, скрытие, заметки, оценки, коллекции и история.
- DataStore для настроек: отображение скрытых элементов, тема и количество страниц для фоновой предзагрузки.
- WorkManager для фонового обновления при наличии сети; повторные попытки при ошибках.
- TTL кэша: данные считаются устаревшими через 24 часа. Локальный каталог отображается независимо от доступности сети.
- Коллекции пользователя связаны с персонажами через отдельную таблицу `collection_members`.
- Unit-тесты правил фильтрации, коллекций, планирования синхронизации и политики TTL.
- Instrumentation UI-тест проверяет, что фильтр «Не нравится» виден и выбирается.

## Технологии
Kotlin, Jetpack Compose, Room, DataStore Preferences, WorkManager, Retrofit, Kotlinx Serialization, Coroutines/Flow, JUnit.

## Запуск
1. Открой папку проекта `FINALWORK1` в Android Studio.
2. Дождись Gradle Sync и установи Android SDK 36, если IDE попросит.
3. Запусти конфигурацию `app` на эмуляторе или устройстве.
4. Для первой загрузки каталога нужен интернет. После загрузки данные читаются из Room и остаются доступны без сети.
5. Unit-тесты: `app/src/test/java/com/example/finalwork1/domain/`.

`local.properties`, папки сборки и кэши IDE намеренно не включены в архив: Android Studio создаст локальные настройки для конкретного компьютера.
